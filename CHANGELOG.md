# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-09-21

### Added

- Package `coppeliasim_core`
- Jupyter Notebooks

### Changed

- Repository structure
- Standalone Python scripts
- Notebook for the seminar S11
- Installation procedure and example of use in `README.md`

### Deprecated

- `set_speed()` in class `P3DX`

### Removed

- Matlab support

### Fixed

- Scenes compatible with CoppeliaSim 4.10.0
- Lidar data sending
- Typos in `CHANGELOG.md`

### Security

## [0.1.1] - 2026-04-16

### Added

- CHANGELOG file

### Changed

- Python ZMQ API documentation

### Removed

- `config.bash` file

### Fixed

- Broken dependencies Coppelia 4.9.0
